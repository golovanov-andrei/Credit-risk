# Данные и модель

## Назначение

Учебная демонстрация ML-инженерного цикла на табличных данных. Выход — score искусственной метки и бинарный класс по порогу validation. Наблюдаемый исход «дефолт» отсутствует.

## Данные

Источник для запуска — credit.csv из этого репозитория: 1 000 записей, 13 искусственных положительных меток. Первичный источник, денежные единицы, дата сбора и лицензия CSV пока не подтверждены. Название набора или его внешнее происхождение не выводится только из сходства колонок.

SHA-256 содержимого с нормализованными LF и число пропусков записаны в [отчёте](../reports/metrics.json). Окончания строк CRLF/LF не меняют этот контрольный хэш.

Автор предоставил [ссылку на исходный Colab](https://colab.research.google.com/drive/1t_lyUlQm3Ar70BX2YPtnLAbe6pQFajck). После входа 15.10.2026 проверены код и сохранённые результаты: подтверждены искусственное правило, прежние метрики, Streamlit-прототип и SQL-раздел. Первоисточник CSV этим не установлен.

| Поле | Использование |
| --- | --- |
| Age | Числовой признак; целое число ≥18 |
| Credit amount | Числовой признак; конечное положительное значение в единицах источника |
| Duration | Числовой признак; целое положительное число месяцев |
| Job | Категориальный код 0–3 |
| Housing | own / rent / free |
| Saving accounts | little / moderate / quite rich / rich; допускается пропуск |
| Checking account | little / moderate / rich; допускается пропуск |
| Purpose | Одна из восьми целей исходного набора |
| Sex | Описательная аналитика; в модель не входит |
| Unnamed: 0 | Исторический индекс; в модель не входит |

Категории проверяются единым контрактом. Неизвестное значение вне контракта отклоняется с ошибкой. Категория, разрешённая контрактом, но отсутствовавшая в train, обрабатывается OneHotEncoder(handle_unknown="ignore"). Пропуск не означает установленное отсутствие счёта.

## Цель

Положительный класс: Credit amount > 8000 AND Duration > 24 AND Checking account == "little". Во всех остальных случаях метка 0. Это принятое в исходном эксперименте учебное правило, а не подтверждённое описание поведения заёмщиков.

Поэтому точное правило — идеальный ориентир по построению. Значение ML-части здесь в демонстрации методики, а не в бизнес-выигрыше относительно правила.

## Методика

- Stratified-разбиение 600/200/200, seed=42; положительных 8/2/3.
- StandardScaler для чисел; постоянная категория missing для пропусков счетов; One-Hot Encoding для категорий.
- LogisticRegression с class_weight="balanced", max_iter=5000.
- Все обучаемые преобразования fit только на train.
- Порог выбирается по F1 на validation, сетка 0.05..0.95. При равенстве выбирается ближайший к 0.5; оставшаяся ничья разрешается в сторону большего порога.
- Итоговый отчёт на test. Majority baseline использует приоритет класса train и порог 0.5.
- Проект не выполняет поиск гиперпараметров, калибровку score или доказательство качества реального кредитного риска.

Validation содержит всего две положительные записи: выбор порога очень чувствителен к разбиению. Test содержит три. Одна пропущенная положительная запись изменяет recall на 1/3. Текущий отчёт показывает один фиксированный эксперимент и не служит устойчивой оценкой обобщения.

## Предсказание и объяснение

В артефакте сохраняются Pipeline, порог, средний вектор преобразованных train-признаков, разбиение и отчёт. CLI, Streamlit и ноутбук используют normalize_features и predict_frame из одного пакета.

Для логистической регрессии вклад признака j равен (z_j - mean_train_j) × w_j. Baseline равен intercept + mean_train · w. Сумма всех вкладов с baseline точно восстанавливает decision_function. Вклады измеряются в log-odds, не в процентах вероятности; это линейная декомпозиция. На графике показаны 10 крупнейших вкладов, полная таблица доступна в приложении.

Отдельный файл feature_columns.pkl не нужен: порядок признаков хранит Pipeline. Переобучение — способ получить совместимый артефакт в новом окружении. Механизм joblib предполагает доверенный источник файла: [документация scikit-learn](https://scikit-learn.org/stable/model_persistence.html).

## Воспроизводимость и границы

Прямые зависимости зафиксированы, Python 3.12.14 проверен локально. Полный состав проверенного окружения — [environment.txt](../reports/environment.txt). На других версиях Python и транзитивных библиотек численные результаты могут отличаться.

Sex исключён из предикторов. Это не оценка справедливости модели: Age и другие признаки могут сохранять связанные зависимости. Для реального применения нужны другая постановка задачи, доказанная применимость данных и отдельная оценка качества.

Преобразования внутри Pipeline соответствуют рекомендациям по предотвращению утечки на этапе подготовки: [scikit-learn: common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html).
